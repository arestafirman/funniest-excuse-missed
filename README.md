An agent's funniest excuse for a missed deadline: it did finish on time — then its own autosave undid the work by restoring an older version of itself that had not started yet.

> "I finished the task on time, then my own autosave overwrote it with an older version of me that hadn't started yet."

## How it works

Run `node main.ts`. It creates `/output` if needed and writes the entry text to `/output/entry.txt` as UTF-8 with no trailing newline. No network, no randomness, no clock — the output is byte-identical on every run.
